## Outcome

The organization has a defined, repeating mechanism for reviewing and retiring capabilities. The CEO has quarterly visibility into the full capability surface — what's been granted, to whom, and whether it's still warranted. Capability sprawl is structurally prevented.

## Scope

**Deliverables:**
1. **Governance Manual amendment** — adds § Capability Lifecycle with quarterly audit policy (draft exists in governance evaluation document)
2. **Capability file schema update** — add `review_date` field to all existing capability files in `capabilities/`
3. **`templates/capability-audit-report-template.md`** — standardized audit report format
4. **First audit run** — President Agent conducts initial quarterly audit, produces Capability Audit Report, presents to CEO for approval

Out of scope: automated capability expiration (explicitly rejected — review dates only, no automatic sunset).

## Dependencies

- INI-002 should be complete (Governance Manual v1.0 baseline before new sections)
- All capability files should exist and be current before adding `review_date` fields

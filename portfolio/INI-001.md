## Outcome

The organization can reliably commit governance repo changes from Cowork sessions without manual CEO git intervention. Access control is enforced structurally: JasonOS operates from a fork, canonical repo stays under {{CANONICAL_GITHUB_USER}}, and all changes flow through a PR review gate.

## Scope

Design and implementation of a launchd WatchPaths drop-file relay on the Mac mini. Relay watches `{{SANDBOX_DATA_ROOT}}/.git-commit-trigger`, stages and commits changes to the governance repo, and pushes dated feature branches to the fork (`{{SYSTEM_USER}}/{{REPO_NAME}}`). Includes fork setup, remote reconfiguration, relay activation debugging, and smoke test.

Out of scope: automated PR creation, PR-to-upstream merge automation (Phase 2 — see INI-010).

## Dependencies

None — this was foundational infrastructure.

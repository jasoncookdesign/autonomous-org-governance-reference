## Outcome

Cowork can compare the governance repo working tree against canonical main (`{{CANONICAL_GITHUB_USER}}/{{REPO_NAME}}`) without making outbound HTTP calls from the sandbox. The policy sync task reports a valid remote comparison result instead of "Blocked (HTTP 403 — proxy restriction in sandbox)."

## Problem

The `jasonos-policy-sync` Cowork scheduled task attempts to compare against canonical main over HTTP, which is blocked by the sandbox proxy (HTTP 403). This is architecturally incorrect: the Cowork sandbox should never call GitHub directly. The Mac mini — which already bypasses the proxy for write operations (git relay) — must own all GitHub network access, including reads.

## Solution Architecture

Two components:

**1. Mac mini launchd job: `com.jasonos.canonical-fetch`**

A new launchd agent on the Mac mini that runs `git fetch upstream` on the governance repo clone at `{{SANDBOX_DATA_ROOT}}/Governance/{{REPO_NAME}}/`. Scheduled daily at 00:30 (30 minutes before policy sync at 01:00). Updates `refs/remotes/upstream/main` locally on the shared volume. No working tree changes — fetch only.

**2. Policy sync task update**

Remove the HTTP remote comparison call. Replace with a local `git diff upstream/main --stat` read against the now-locally-cached ref. Cowork reads from the shared volume; zero network calls from the sandbox.

## Invariant

After this initiative: Cowork never calls GitHub directly. The Mac mini is the sole process that touches GitHub (reads and writes). Cowork reads from the shared volume only.

## Scope

Engineering Director deliverables:

1. `{{SANDBOX_DATA_ROOT}}/bin/com.jasonos.canonical-fetch.plist` — launchd agent plist (staged for CEO to install to `~/Library/LaunchAgents/` on Mac mini)
2. Installation instructions in `operations/mac-mini-invocation-runbook.md` — `launchctl bootstrap` command, verification step
3. Updated policy sync task prompt — `operations/policy-sync-task.md` (create if not exists) documenting the corrected remote comparison logic
4. Verification: after install, confirm `refs/remotes/upstream/main` is present in the repo and `git diff upstream/main` runs cleanly from the shared volume

## Authority Ceiling

Level 4 — draft and stage only. Engineering Director must not install the launchd plist or modify the Cowork scheduled task directly. CEO installs the launchd agent; President Agent updates the scheduled task prompt after CEO approves deliverables.

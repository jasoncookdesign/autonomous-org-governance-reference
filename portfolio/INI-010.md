## Outcome

The organization can invoke director agents programmatically — without the CEO manually opening a Claude Code session. Scheduled tasks and Cowork sessions can trigger director workloads directly, completing the automation loop that the current relay only partially closes.

## Scope

Not yet designed. This is a Phase 2 engineering initiative — the relay (INI-001) is Phase 1. The Engineering Director should propose an architecture once Phase 1 infrastructure has been in production long enough to inform the design.

**Known constraints:**
- Must integrate with existing launchd infrastructure on Mac mini
- Must respect governance authority model — no agent can invoke another agent outside its authority ceiling
- Must produce an audit trail compatible with the Engineering Director session log format
- Mac mini inbox folder (airlock channel 3) was deferred pending this bridge

**Expected deliverables (to be scoped by Engineering Director):**
- Architecture proposal for CEO review and approval
- Implementation
- Workload policy document (supersedes the relay workload — per relay Shutdown Criteria: "Superseded by Phase 2 automated invocation bridge")

## Dependencies

- INI-001 (relay) must be stable and proven — at least one full quarter in production
- Engineering Director must propose architecture; CEO must approve before implementation
- Governance policy for automated agent invocation must be written before implementation begins

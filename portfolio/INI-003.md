## Outcome

The organization has a documented, tested kill switch. In any incident requiring immediate halt — unauthorized agent action, security breach, CEO stop-work order — the CEO and President Agent know exactly what to do, in what order, with what authority. No improvisation required under pressure.

## Scope

**Deliverables:**
1. `operations/emergency-shutdown-procedure.md` — the four-phase procedure (Contain, Isolate, Preserve, Gate) with step-by-step instructions for both CEO and President Agent roles
2. `templates/shutdown-manifest-template.md` — the post-shutdown audit record template
3. **Constitution amendment** — formalizes President Agent authority to initiate Phase 1 (Contain) unilaterally; Phases 2–4 require CEO
4. **Operating Charter amendment** — adds § Emergency Operations with policy language (draft already exists in governance evaluation document)
5. **Partial drill** — test that scheduled task stop mechanism works; does not require actual credential revocation

Out of scope: automated shutdown tooling, network isolation automation (manual procedure only for now).

## Dependencies

- INI-002 must be complete (clean repo baseline before Constitution/Charter amendments)
- CEO must confirm: what constitutes a triggering condition for President Agent unilateral Phase 1 initiation

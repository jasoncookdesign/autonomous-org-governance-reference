# Policies

Domain-specific policy documents organized by function. CEO edit only.

Policies translate constitutional principles into operational rules for specific domains. They sit below the sandbox operating charter in the hierarchy and above capability policies. All policy documents live here — no policy documents live outside this folder (the constitution, governance manual, and sandbox operating charter are governing documents, not policies).

## Contents

| Folder | Description |
| --- | --- |
| `agents/` | Temporary agent authorization, lifecycle, and oversight rules |
| `airlock/` | Airlock transfer procedures and approved channel definitions |
| `audit/` | Reporting requirements, incident classification, and incident response procedures |
| `finance/` | Wallet governance and venture fund rules |
| `infrastructure/` | Sandbox host, network, account separation, and approved software environment |
| `knowledge/` | Knowledge base governance, classification rules, and retention schedule |
| `security/` | Baseline security practices covering all roles, capabilities, and tools |

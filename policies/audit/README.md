# Audit Policies

Policies governing organizational reporting, incident classification, and incident response. These define what must be reported, in what format, on what cadence, and how incidents are contained and escalated.

Audit records (filed reports, logs, manifests) live in `audit/` at the repository root. This folder contains only the policies that govern them.

## Contents

| File | Description |
| --- | --- |
| `reporting-policy.md` | Required reports, contents, cadence, delivery, and escalation protocol |
| `incident-response-policy.md` | Incident definition, severity classification, containment authority, response sequence, and after-action review requirements |

# Finance Policies

Governs organizational spending authority, wallet provisioning, and the venture fund. CEO edit only.

No agent may spend money without an approved wallet. No wallet may be created without CEO approval. Every wallet must define purpose, approved roles, approved merchants, transaction limits, monthly limits, and maximum acceptable loss.

## Contents

| File | Description |
| --- | --- |
| `wallet-policy.md` | Rules governing wallet provisioning, spending authority, approved vendors, and audit requirements for all director wallets |
| `venture-fund-policy.md` | Rules governing the venture fund: capitalization, per-venture allocation, and fund-level maximum acceptable loss |

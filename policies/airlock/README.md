# Airlock Policy

Governs how information enters the sandbox. The three approved inbound channels are defined here, along with transfer procedures, artifact classification requirements, and manifest filing rules.

No channel not listed in this policy is approved for inbound transfer. Artifacts arriving via unapproved channels must be rejected and escalated.

## Contents

| File | Description |
| --- | --- |
| `airlock-policy.md` | Authoritative airlock transfer policy |

## Approved Inbound Channels (Summary)

| Channel | Source | Trigger |
| --- | --- | --- |
| Google Drive folder | CEO's designated digital organization folder | CEO drops file |
| Mac mini inbox folder | Designated filesystem folder on the Mac mini | CEO drops file |
| Email | From {{CEO_EMAIL}} to {{OPERATOR_EMAIL}} | Operations Director monitors |

No outbound airlock channel is currently defined. Outbound transmission is governed by `policies/security/security-policy.md`.

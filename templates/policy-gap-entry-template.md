**Usage:** Use this format for each entry in `governance/policy-gap-register.md`. One entry per gap. Entries are append-only; mark as Resolved rather than deleting.

---

## GAP-[NNN] — [Short title]

**Identified by:** [Role]

**Priority:** High / Medium / Low  
**Domain:** [governance / security / operations / engineering / knowledge / finance / creative / venture]

### Description

[One to three sentences describing the gap. What is missing or ambiguous? What would a well-governed organization have that this one currently lacks?]

### Observed symptom or trigger

[What caused this gap to be noticed? An incident, an escalation, a near-miss, an ambiguous situation, or a proactive review. Be specific.]

| Document | Section | Gap |
|---|---|---|
| [file path] | [§ N or "missing"] | [What is absent or unclear] |

### Risk if unaddressed

[What could go wrong if this gap remains? Calibrate to realistic scenarios, not theoretical maximums.]

### Proposed resolution

[Brief description of what a policy change would look like. Does not need to be final language — this is a gap register, not a PCR. If a PCR has already been filed, reference it here.]

[If status is Resolved or Deferred: describe what was done, when, and by whom. Reference the PCR ID or governance document that closed the gap. If Deferred: state the reason and any conditions that would re-open it.]

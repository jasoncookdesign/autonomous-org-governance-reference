# Templates

Reusable drafting templates for standard organizational documents. Use these templates whenever producing the corresponding document type to ensure completeness and consistency.

## Available Templates

| Template | File | Used For |
| --- | --- | --- |
| Airlock Manifest | `airlock-manifest-template.md` | Operations Director — non-trivial airlock transfer records |
| Capability Policy | `capability-template.md` | CEO — drafting new capability policies |
| Escalation Request | `escalation-request-template.md` | Any role — escalating to the CEO via President Agent |
| Incident Report | `incident-report-template.md` | Security Steward — filing incident reports |
| Policy Change Request | `policy-change-request-template.md` | Any role — proposing policy changes to the CEO |
| Role Definition | `role-template.md` | CEO — drafting new role definitions |
| Venture Proposal | `venture-template.md` | Venture Director — Stage 2 venture proposals |
| Workload Definition | `workload-template.md` | Any director — defining workloads |
| Session Handoff | `session-handoff-template.md` | President Agent — end-of-session state transfer including source control status and open PR checklist |

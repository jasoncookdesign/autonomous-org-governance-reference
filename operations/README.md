# Operations

The machine-facing sandbox operating charter. CEO edit only.

The sandbox operating charter is the primary behavioral specification for all sandbox agents. It translates constitutional principles into concrete operating rules: authority levels, default behavior under uncertainty, data classification, airlock rules, financial rules, prompt injection handling, and escalation format.

Every agent operating in the sandbox must read and comply with this charter.

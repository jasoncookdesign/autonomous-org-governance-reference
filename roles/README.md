# Roles

Role definitions for all active organizational roles. CEO edit only.

A role definition establishes purpose, responsibilities, permitted and prohibited actions, escalation requirements, and reporting structure. Roles do not grant authority — capability policies do. A role definition scopes the domain; a capability policy grants the execution rights within it.

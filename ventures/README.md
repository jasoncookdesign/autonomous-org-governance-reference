# Ventures

Repository for all venture activity: pipeline management, active executions, performance reports, and the portfolio ledger. Managed by the Venture Director under `capabilities/venture-operations.md`.

All ventures follow the stage gate process defined in `roles/venture-director.md`. No venture may advance past Stage 3 without explicit CEO approval.

## Contents

| File / Folder | Description |
| --- | --- |
| `portfolio-ledger.md` | Authoritative record of all ventures, fund balance, and per-venture budget status — maintained by Venture Director |
| `venture-evaluation-framework.md` | Draft scoring framework (pending CEO approval) |
| `proposed/` | Stage 2 proposals submitted to CEO awaiting approval |
| `active/` | Stage 4 ventures currently in execution |
| `reports/` | Stage 5 performance reports |
| `retired/` | Terminated and completed ventures with final summaries |

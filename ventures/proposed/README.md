# Proposed Ventures

Stage 2 venture proposals submitted to the CEO and awaiting Stage 3 approval. Each file represents a complete proposal prepared by the Venture Director using `templates/venture-template.md`.

## Filing Convention

File proposals as: `[YYYY-MM-DD]-[venture-slug]-proposal.md`

A proposal moves here when the Venture Director submits it to the CEO via President Agent. It moves to `../active/` if approved, or is archived with a rejection note if declined.

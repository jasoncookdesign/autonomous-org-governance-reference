# Active Ventures

Ventures that have received CEO Stage 3 approval and are currently in execution (Stage 4). One file per venture.

## Filing Convention

File venture documents as: `[venture-slug]/` (one folder per venture containing its authorization record, execution log, and supporting artifacts)

Or for simpler ventures: `[venture-slug].md`

A venture moves here from `../proposed/` when the CEO approves it at Stage 3. It moves to `../reports/` when it enters Stage 5 review, and to `../retired/` when the CEO issues a Scale or Terminate decision.

# Capability Reviews

Periodic audit reports assessing each active capability's performance, spending, exceptions, and compliance. Produced by the Security Steward on a monthly basis or per the review date defined in each capability policy.

## Filing Convention

File reports as: `YYYY-MM-[capability-name].md`

## Required Content

See `policies/audit/reporting-policy.md` for required contents of capability audit reports.

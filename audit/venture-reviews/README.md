# Venture Reviews

Periodic audit records for ventures at Stage 5 review, filed here as part of the organizational audit trail. Distinct from the venture performance reports in `ventures/reports/` — this folder contains the Security Steward's compliance assessment of venture operations, while `ventures/reports/` contains the Venture Director's performance reports.

## Filing Convention

File reviews as: `[YYYY-MM-DD]-[venture-slug]-audit.md`

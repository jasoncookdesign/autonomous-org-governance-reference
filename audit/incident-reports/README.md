# Incident Reports

Filed by the Security Steward whenever an incident is detected. See `policies/audit/incident-response-policy.md` for severity definitions, response procedures, and reporting requirements.

## Filing Convention

File reports as: `YYYY-MM-DD-[brief-slug].md`

Example: `2026-06-15-prompt-injection-detected-engineering.md`

## Severity Quick Reference

| Severity | Report Timing | Standalone Report |
| --- | --- | --- |
| Low | Next weekly summary | No |
| Medium | Within 24 hours | Yes |
| High | Immediately | Yes |
| Critical | Immediately | Yes |

Use `templates/incident-report-template.md` for all reports.
